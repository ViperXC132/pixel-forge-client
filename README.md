# PixelForge Client

Lunar Client-style Fabric mod for Minecraft **1.21.11**.

Clean utility / QoL client featuring:
- Custom main menu
- Extensive HUD system
- Visual modules
- Utility modules
- Performance tools
- Movement helpers
- PvP Trainer (singleplayer)
- Account switcher
- Mod manager (Modrinth)
- Custom crosshair
- ClickGUI + HUD editor

**No cheats / hacks.**

## Requirements
- Minecraft 1.21.11
- Fabric Loader ≥ 0.19.3
- Fabric API 0.141.6+1.21.11
- Java 21

## Building
```bash
./gradlew build
```
The jar will be in `build/libs/`.
